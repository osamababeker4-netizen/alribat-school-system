# مدرسة الرباط — Alribat School System

نظام مالي وإداري مركزي عربي متجاوب لمدرسة الرباط الأساسية المختلطة الخاصة — بورتسودان.

## رابط التشغيل
https://alribat-school-system.onrender.com

## الإصدار
**v1.6.0 — Operations & Employee Attendance Upgrade**

## الوظائف التشغيلية
- تسجيل دخول حقيقي عبر Supabase Auth.
- قاعدة بيانات مركزية ومزامنة لحظية بين الأجهزة.
- أدوار وصلاحيات: مدير النظام، مدير المدرسة، محاسب، أمين المستودع، مشرف/معلم.
- تسجيل المستخدمين مغلق: الحساب الأول المصرح به أو دعوة صادرة من الإدارة فقط.
- الطلاب، الرسوم، التحصيل، إيصالات القبض، المصروفات، الموظفون، حضور الطلاب، حضور وانصراف الموظفين، المخزون، الطلبات والموافقات، التقارير.
- منع دفع أكثر من الرصيد ومنع الصرف بالسالب ومنع حذف طالب مرتبط بحركات مالية.
- سجل تدقيق، تنبيهات، CSV، JSON backup، والطباعة/PDF.
- لوحة تشغيل مطورة بألوان الهوية الرسمية، انتقالات ديناميكية، مؤشرات لحظية، وتصميم متجاوب للجوال والكمبيوتر.
- شعار المدرسة في الواجهة وشاشة الدخول.
- ترويسة وتذييل وعلامة مائية وختم في المستندات المطبوعة.
- إيصالات قبض رسمية قابلة للطباعة والحفظ PDF.

## سلامة البيانات
- RLS مفعّل، والوصول المباشر للجداول العامة مقصور على القراءة حسب الدور.
- لا وصول مجهول للجداول.
- الكتابة المركزية وإدارة حالة المستخدمين وتحديث رقم الجوال تمر عبر RPC آمن ومحدد الصلاحيات.
- Optimistic concurrency يمنع الكتابة الصامتة فوق تعديل مستخدم آخر.
- آخر 50 نسخة لكل وحدة تحفظ تلقائيًا في سجل استرجاع داخلي.

## ملاحظات أمان الإنتاج
- استخدم `VITE_SUPABASE_PUBLISHABLE_KEY` للواجهة عند توفره، ولا تستخدم `service_role` في المتصفح.
- الكتابة الحساسة لا تتم مباشرة على الجداول؛ تمر عبر RPC محمي بالصلاحيات.
- يوصى بتفعيل **Leaked Password Protection** من إعدادات Supabase Auth إذا كانت الخطة تدعمها.
- في بيئة الإنتاج يفشل النظام بشكل آمن إذا كانت إعدادات Supabase غير مكتملة، ولا ينتقل إلى تخزين محلي صامت.
- حالة المزامنة تظهر منذ لحظة انتظار الحفظ، مع معالجة أوضح لأخطاء تسجيل الدخول واستعادة الجلسة.
